**Project: Loan Disbursement System**

**1. Backend (Spring Boot)**

*   **Description:** A RESTful API for managing loan applications, including user authentication, loan application submission, and admin review.
*   **Dependencies:**
    *   `spring-boot-starter-web`: For building web applications.
    *   `spring-boot-starter-security`: For authentication and authorization.
    *   `spring-boot-starter-data-jpa`: For database access.
    *   `postgresql`: PostgreSQL JDBC driver.
    *   `jjwt-api`, `jjwt-impl`, `jjwt-jackson`: For JWT creation and validation.
    *   `springdoc-openapi-starter-webmvc-ui`: For Swagger/OpenAPI documentation.
*   **Configuration (`application.properties`):**
    *   `server.port=9000`
    *   `spring.datasource.url=jdbc:postgresql://localhost:5432/loan_disbursement`
    *   `spring.datasource.username=postgres`
    *   `spring.datasource.password=postgres`
    *   `spring.jpa.hibernate.ddl-auto=create-drop`
    *   `jwt.secret`: A secure 512-bit key.
    *   `jwt.expiration=86400000`
*   **Key Features:**
    *   **Authentication:** JWT-based authentication with "admin" and "user" roles.
    *   **Admin User:** A default admin user is created on startup with the username "admin" and password "admin".
    *   **CORS:** Configured to allow requests from `http://localhost:3000` with credentials.
    *   **Swagger:** Configured to allow JWT authentication for testing protected endpoints.

**2. Frontend (React)**

*   **Description:** A single-page application for users to apply for loans and for admins to manage applications.
*   **Dependencies:**
    *   `axios`: For making HTTP requests to the backend.
    *   `react-router-dom`: For routing.
    *   `tailwindcss`: For styling.
*   **Configuration:**
    *   An `axios` instance is configured with `baseURL: 'http://localhost:9000'` and `withCredentials: true`.
*   **Key Features:**
    *   **User Dashboard:** Allows users to view their loan applications and submit new ones.
    *   **Admin Dashboard:** Allows admins to view all loan applications, filter them by status, and update their status.
    *   **Login/Register:** Separate pages for user login and registration.

**3. Database (PostgreSQL)**

*   **Schema (`postgresql_schema.sql`):**
    *   **`users` table:** Stores user information, including username, password (hashed), email, full name, and role (`USER` or `ADMIN`).
    *   **`loan_applications` table:** Stores loan application details, including amount, term, purpose, status (`SUBMITTED`, `APPROVED`, `REJECTED`, `DISBURSED`), and foreign key to the `users` table.
    *   **`disbursements` table:** Stores disbursement information, including a foreign key to the `loan_applications` table and a transaction reference.
*   **Data Initialization:**
    *   A `CommandLineRunner` in the backend creates a default admin user on startup.
